Suggested toolboxes and packages for working with geospatial data in MATLAB 

 

Suggested toolboxes 

    Curve Fitting Toolbox                                

    Mapping Toolbox                                        

    Statistics and Machine Learning Toolbox 

 

Suggested third-party packages: 

    nctoolbox: A MATLAB toolbox for working with common data model datasets. https://github.com/nctoolbox/nctoolbox  

    M_Map: An excellent mapping package. https://www.eoas.ubc.ca/~rich/map.html  

    For great colormap choices, you can also add ColorBrewer: https://www.mathworks.com/matlabcentral/fileexchange/45208-colorbrewer-attractive-and-distinctive-colormaps  

 

If you’re going to work with netCDF files, or large climate datasets, you may also want to install these on your computer and then call their commands using MATLAB: 

    NCO (NetCDF Operators): https://nco.sourceforge.net/  

    CDO (Climate Data Operators): https://code.mpimet.mpg.de/projects/cdo
